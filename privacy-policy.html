Політика конфіденційності

Дата набрання чинності: 18 вересня 2026 року

VARTO — мобільний застосунок для управління особистими фінансами, обліку доходів, витрат, активів та криптовалютного портфеля.

Ця Політика конфіденційності пояснює, які дані можуть оброблятися під час використання VARTO та для чого вони використовуються.

1. Які дані ми збираємо

Дані облікового запису:

  • адреса електронної пошти;
  • ідентифікатор користувача;
  • дані, необхідні для автентифікації та роботи облікового запису.

Фінансові дані, які користувач додає самостійно:

  • доходи та витрати;
  • категорії операцій;
  • суми та валюти;
  • фінансові цілі;
  • активи та криптовалютні операції;
  • інформація про купівлю та продаж активів.

VARTO не продає персональні або фінансові дані користувачів.

2. Як ми використовуємо дані

  • для створення та підтримки облікового запису;
  • для синхронізації даних між пристроями;
  • для відображення доходів, витрат та активів;
  • для розрахунку фінансової статистики;
  • для роботи криптовалютного портфеля;
  • для надсилання push-сповіщень, якщо користувач надав дозвіл;
  • для обробки та відновлення покупок у застосунку;
  • для забезпечення безпеки та технічної роботи VARTO.

3. Зберігання даних

Для роботи VARTO може використовуватися інфраструктура Supabase. Дані облікового запису та фінансові дані передаються через захищене з'єднання та зберігаються відповідно до налаштувань сервісу.

4. Криптовалютні дані

VARTO може використовувати CoinGecko для отримання актуальної інформації про ціни криптовалют. Ринкові дані використовуються для розрахунку вартості активів та статистики в застосунку.

5. Покупки та підписки

VARTO може пропонувати платні функції або підписки через Apple In-App Purchase. Платіжні дані обробляються Apple відповідно до її правил. VARTO не отримує та не зберігає повні реквізити банківської картки користувача.

Для перевірки статусу підписки можуть оброблятися технічні дані покупки, зокрема ідентифікатор продукту, ідентифікатори транзакції та інформація про термін дії підписки.

6. Push-сповіщення

VARTO може використовувати push-сповіщення для нагадувань про фінансові цілі, змін у портфелі та інших повідомлень, пов'язаних із роботою застосунку. Користувач може дозволити або заборонити їх у налаштуваннях пристрою.

7. Передача даних третім сторонам

Для забезпечення роботи окремих функцій можуть використовуватися сторонні постачальники:

  • Supabase — автентифікація та зберігання даних;
  • Apple — розповсюдження застосунку та обробка покупок;
  • CoinGecko — отримання ринкових даних;
  • Expo та відповідна інфраструктура — технічне забезпечення окремих функцій і push-сповіщень.

Ми не продаємо персональні дані користувачів рекламодавцям або іншим третім сторонам.

8. Безпека

Ми застосовуємо технічні та організаційні заходи для захисту інформації від несанкціонованого доступу, зміни, розкриття або знищення. Водночас жоден спосіб передачі чи зберігання даних через Інтернет не може гарантувати абсолютну безпеку.

11. Зміни до Політики конфіденційності
